# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, aceite críticas construtivas, foque no que é melhor
para a comunidade. Assédio, ataques pessoais, linguagem discriminatória e exposição de dados
privados de terceiros não são tolerados.

Para relatar um comportamento, use os contatos do perfil do mantenedor no GitHub
([@GuiBonin](https://github.com/GuiBonin)). Os relatos são tratados com confidencialidade.
